# Лекция 6. Поиск кратчайшего пути

## Алгоритм Дейкстры
Алгоритм Дейкстры находит кратчайшие пути от одной вершины до всех остальных во взвешенном графе с неотрицательными весами.
Использует приоритетную очередь.

## BFS для кратчайшего пути
В невзвешенном графе кратчайший путь находится с помощью BFS.
Каждое ребро имеет вес 1.

## Пример
Для графа без весов BFS даёт оптимальный путь за O(V + E).
